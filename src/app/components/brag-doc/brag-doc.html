02 / Current Engineering

Sigil Books AI Listing Platform

An AWS-based resale automation platform designed to move physical books from photography through identification, pricing, inventory management, human review, and marketplace export.

  • Designed an inventory workflow with explicit processing, pricing, review, export-readiness, and marketplace-export state.
  • Integrated AI-assisted product identification and pricing into an operational inventory workflow.
  • Built around AWS services including DynamoDB and S3 with Python/FastAPI application services.
  • Implemented asynchronous status tracking so the UI can communicate long-running processing state to the operator.
  • Investigated and corrected failure modes involving missing pricing, duplicate exports, export eligibility, and inconsistent workflow state.
  • Designed toward an operational target of approximately 50 books per day.
